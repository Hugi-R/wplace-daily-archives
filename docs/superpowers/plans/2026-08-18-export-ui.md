# Export UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Screenshot/Video buttons with a single Export panel that exports the map area as a static PNG or Animated PNG at a chosen z level and tile range, with live map preview (selection rectangle; APNG end-frame preview), and with APNG supported at every stored z level.

**Architecture:** The frontend is a single vanilla-JS `index.html` (no framework). The export panel is a docked right-side panel; while open, all other chrome is hidden. The proven Rust WASM encoders (`wasm_screenshot`, `wasm_video`) are reused — they get a `z` parameter. The tileserver's `/diff/all` endpoint drops its `z==11` restriction so APNG works at all stored z (0..9, 11). z=10 is never offered (not stored).

**Tech Stack:** Rust (axum/r2d2/rusqlite tileserver, wasm-bindgen WASM lib), vanilla JS + Maplibre GL in `frontend/index.html`, `wasm-pack` for the WASM build, SQLite week DBs in `tmp/weeks/` for verification.

## Global Constraints

- z level `10` is never offered for export (nothing stored; merge skips it and builds z=9 directly from z=11).
- Every stored z level uses 1000×1000 px tiles — no resize/scale logic anywhere in export.
- Caps: PNG ≤ **400** tiles, APNG ≤ **64** tiles. Exceeding disables export with a red hint.
- Versions are `DateHours` (u32, hours since `2025-01-01T00:00:00Z`); the dropdowns carry the integer `version` as the option value and the formatted date as the label; `wasm_screenshot`/`wasm_video` receive these integers directly.
- `frontend` is a standalone workspace (`cargo build` from repo root does NOT build it; use `build_server.sh` which runs `wasm-pack`).
- Follow the existing inline-script conventions in `index.html`; do not add gratuitous comments; keep new CSS in the existing `<style>` block using its CSS variables.
- The WASM lib exports `wasm_screenshot` and `wasm_video`; changing their signatures requires a wasm rebuild before manual E2E.

      document.body.classList.add('export-open');
      exportPanel.classList.add('open');

      const zSel = document.getElementById('export-z');

      exportParams.z = defaultExportZ();
      zSel.value = exportParams.z;
      const z = exportParams.z;
      const b = map.getBounds();
      const maxT = Math.pow(2, z) - 1;

      const start = document.getElementById('export-start');
      const end = document.getElementById('export-end');
