# SEO: server-generated robots.txt and sitemap.xml

Date: 2026-08-22

## Goal

Give crawlers explicit crawl directives and a canonical URL map for the
multilingual site (`/en/`, `/ja/`, `/es/`):

- `/robots.txt`: block the binary data endpoints, declare the sitemap.
- `/sitemap.xml`: one entry per language page with hreflang alternates and
  `lastmod`.

Both files are generated by the tileserver so URLs stay derived from
`Lang::ALL` and `SITE_BASE` — the same source of truth as the canonical and
hreflang links already rendered into the index pages.

## Current state

- `frontend/index.html` is a template rendered per language at startup by
  `build_index` (`tileserver/src/main.rs`). Canonical, hreflang alternates,
  Open Graph and Twitter meta already exist in the page head; no changes are
  needed there.
- `SITE_BASE = "https://wplace.eralyon.net"` is a const in main.rs; language
  codes come from `Lang::code()`, URL paths from `Lang::path()`; the
  x-default target is `Lang::En`.
- Routes are registered in `build_router`. Static single-body responses
  (`/preview.png`, `/favicon.ico`, assets) are served through
  `cached_response`, which adds `Cache-Control: public, max-age=3600` and a
  content-crc32 ETag with If-None-Match handling.
- There is no robots.txt and no sitemap.xml.

## Design

### Builder functions (main.rs, next to `build_index`)

```rust
fn build_robots_txt() -> String
fn build_sitemap_xml(latest_epoch_hour: u32) -> String
```

Both pure functions over constants / the latest date, pre-rendered once at
startup like the index pages (data only changes on restart, so per-request
generation buys nothing).

**robots.txt**:

```
User-agent: *
Disallow: /tiles/
Disallow: /diff/

Sitemap: https://wplace.eralyon.net/sitemap.xml
```

`/tiles/` and `/diff/` are heavy binary endpoints with no SEO value; blocking
them conserves crawler budget. `/assets/` stays allowed so search engines can
render the page (JS/WASM/CSS).

**sitemap.xml**: `urlset` schema plus the xhtml namespace. One `<url>` per
language in `Lang::ALL`; every entry carries the complete alternate set
(hreflang for each language + `x-default` → `/en/`), mirroring the hreflang
link tags in the page head. `<lastmod>` is derived from the latest archive
epoch hour via `epoch_hour_to_date`, formatted as W3C datetime, e.g.
`2026-08-15T05:00:00+00:00`. Each entry also carries
`<changefreq>daily</changefreq>`: new snapshot versions land daily and the
rendered HTML changes with them (the embedded version list grows). Note:
Google ignores `changefreq`; `lastmod` is the operative signal there — the
tag remains a useful hint for other crawlers and documents intent. The root
`/` is intentionally excluded — it is an Accept-Language redirect, not
canonical content; sitemaps should list only 200-OK canonical URLs.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:xhtml="http://www.w3.org/1999/xhtml">
  <url>
    <loc>https://wplace.eralyon.net/en/</loc>
    <xhtml:link rel="alternate" hreflang="en" href="https://wplace.eralyon.net/en/"/>
    <xhtml:link rel="alternate" hreflang="ja" href="https://wplace.eralyon.net/ja/"/>
    <xhtml:link rel="alternate" hreflang="es" href="https://wplace.eralyon.net/es/"/>
    <xhtml:link rel="alternate" hreflang="x-default" href="https://wplace.eralyon.net/en/"/>
    <lastmod>2026-08-15T05:00:00+00:00</lastmod>
    <changefreq>daily</changefreq>
  </url>
  <!-- identical structure for /ja/ and /es/ -->
</urlset>
```

### State

`TileServer` gains two fields, populated in `TileServer::new` after
`build_index` (which has already validated that `dates` is non-empty):

```rust
robots_txt: Bytes,
sitemap_xml: Bytes,
```

The latest epoch hour for `lastmod` is taken from the same `dates` slice.

### Routing and serving

Two routes added to `build_router`:

```rust
.route("/robots.txt", get(serve_robots))
.route("/sitemap.xml", get(serve_sitemap))
```

Handlers pass the stored bytes through `cached_response` with
`StatusCode::OK`, `text/plain; charset=utf-8` (robots) and
`application/xml` (sitemap), `max_age = Duration::from_secs(3600)`, and the
request's `If-None-Match` — identical to how `/preview.png` and
`/favicon.ico` are served today.

Static route segments take precedence over the existing `/{lang}` param
route in matchit, so `/robots.txt` cannot be captured by it (same mechanism
that keeps `/preview.png` working).

### Error handling

Both builders are infallible: they format strings from `Lang::ALL`,
`SITE_BASE`, and a `u32` epoch hour already validated non-empty by
`build_index` (which aborts startup when no versions exist). At runtime the
handlers only serve prebuilt bytes and cannot fail.

## Testing

- Unit tests for `build_robots_txt`: contains both Disallow rules and the
  Sitemap line pointing at `{SITE_BASE}/sitemap.xml`.
- Unit tests for `build_sitemap_xml` (fixture epoch hour):
  - one `<url>` per language of `Lang::ALL`, correct `<loc>` values;
  - each entry carries alternates for every language plus `x-default`;
  - `lastmod` equals the expected W3C datetime for the fixture input;
  - structural string assertions (no new XML-parsing dependency): prolog
    present, both namespaces declared, `<loc>`/`xhtml:link`/
    `<changefreq>daily</changefreq>` counts match `Lang::ALL`.
- Router tests via the existing `router_fixture` + tower `oneshot` pattern:
  - `GET /robots.txt` → 200, `text/plain`, expected body;
  - `GET /sitemap.xml` → 200, `application/xml`, body contains all three
    `<loc>` entries;
  - `If-None-Match` revalidation returns 304 (covered implicitly by the
    shared helper's existing tests; one integration assertion is enough).

## Out of scope

- JSON-LD structured data, og:image absolute-URL fixups, or other head meta
  changes to `index.html`.
- Search Console submission automation.
- Per-version sitemaps (only one canonical set of pages exists).
